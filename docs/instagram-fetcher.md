# 공개 릴스 캡션 (#20)

공개 릴스 HTML의 og:url이 같은 게시물을 가리키고 og:description/twitter:description에 캡션이 있을 때만 수집해요. 공유 쿼리를 제거한 고정 Instagram 릴스 주소에 접속하며 #19의 공개 IP·시간·크기 제한을 재사용해요. 영상·로그인·비공개 API는 사용하지 않아요.

캡션 없음·로그인 이동·삭제·접근 차단은 SOURCE_FETCH_FAILED예요. 캡션을 만들거나 body의 로그인 문구로 대신하지 않아요. 캡션 최대 2200자, 썸네일은 선택이며 그 실패로 캡션 성공을 막지 않아요. 실패는 #23에서 링크별로 집계해 유튜브 등 다른 성공 결과를 유지해요.

초기 구현은 고정 HTML로 캡션·빈 캡션·차단·로그인 이동을 검증했어요. 운영 주소는 현재 확인됐지만 2026-11-16 사용자 요청으로 추가 테스트·실제 릴스·운영 실호출을 생략해요. 서버 지역·Instagram 차단 정책에 따라 공개 릴스도 실패할 수 있으며 데모는 유튜브를 우선해요. 새 의존성·공유 계약 변경은 없어요.

2026-11-16 보완: 계정 생성·가입을 권하는 일반 Instagram 메타 설명도 캡션으로 넘기지 않아요. 썸네일 처리 후 전체10초 기한을 다시 검사해 기한을 넘긴 부분 결과를 성공으로 반환하지 않아요. 이 보완의 확인 범위는 운영 JAR 빌드예요.

지원하는 것은 로그인 없이 내려온 정적 공개 릴스 HTML의 본인 릴스와 일치하는 메타 캡션이에요. 비공개·삭제·로그인/가입 화면·차단·메타 캡션 없음·시간 초과는 SOURCE_FETCH_FAILED로 그 링크만 실패해요. 로그인 우회·영상 다운로드·JS 렌더링은 제공하지 않아요. 이 문서는 실제 Cloud Run에서 특정 공개 릴스가 성공한다고 보장하지 않아요.
