# 이미지 업로드 (#21)

POST /images의 multipart file은 로그인 회원만 업로드해요. PNG/JPEG, 5MiB 이하, 8192px 이하·총 1600만 픽셀 이하만 허용하며 MIME과 실제 이미지 형식·디코딩을 검사해요. 샘플 디코딩과 메모리 입력을 사용하고 서버 디스크에 영구 저장하지 않아요. 파일명 대신 회원 ID/UUID를 사용해 충돌·경로 주입을 막아요.

201 {imageUrl}을 반환해요. 잘못된 파일은 INVALID_INPUT, 저장소 실패는 IMAGE_UPLOAD_FAILED(500, 제안 문구)예요. GCS_BUCKET과 런타임 서비스 계정의 메타데이터 토큰으로 고정 Cloud Storage REST 주소에 업로드해요. 로컬 검증용 GCP_ACCESS_TOKEN은 선택 비밀 환경 변수예요. 토큰·키는 반환 URL·로그에 넣지 않아요. 업로드 전체 10초·응답 본문 64KiB 제한이며 자동 재시도·리디렉션은 없어요.

버킷 생성·IAM·공개 읽기 설정은 변경하지 않았어요. 반환된 공개 URL이 FE에서 보이려면 #27에서 해당 버킷의 허용된 읽기 정책을 설정해야 해요. 미설정일 때 가짜 성공 주소를 만들지 않아요. 새 SDK·의존성은 없고 자동 테스트는 가짜 StorageClient예요. 실제 버킷 저장·FE 표시 확인은 GCP 설정 후 남아 있어요.
